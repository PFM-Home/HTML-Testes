# 🚀 HTML-Testes

> Um repositório dedicado a explorar, testar e documentar as melhores práticas de **HTML5**, **CSS3** e **JavaScript (ES6+)**.  
> Aqui você encontra exemplos práticos, componentes reutilizáveis e experimentos interativos.

---

## ✨ Sobre o Projeto

Este repositório serve como um **laboratório de desenvolvimento front-end**, onde:

- 🧪 **Testamos** novas APIs e funcionalidades do navegador.
- 🎨 **Exploramos** layouts, animações e estilos modernos.
- ⚡ **Implementamos** lógica de JavaScript interativa e performática.
- 📚 **Documentamos** padrões, erros comuns e soluções criativas.

Ideal para quem quer **aprender, ensinar ou apenas guardar snippets** de código.

---

## 🛠️ Tecnologias Utilizadas

| Tecnologia | Versão | Descrição |
|------------|--------|-----------|
| **HTML**   | 5.3    | Estrutura semântica e acessível |
| **CSS**    | 3.1 / SCSS | Estilização moderna com Flexbox, Grid e variáveis |
| **JavaScript** | ES6+ | Lógica reativa, modular e assíncrona |
